# dploy

A command-line stow/link/unstow utility for managing dotfiles and other
symlinked file trees.

## Agent skills

### Issue tracker

Issues live as GitHub issues in `arecarn/dploy`, managed with the `gh` CLI. See
`docs/agents/issue-tracker.md`.

### Domain docs

Single-context: `CONTEXT.md` and `docs/adr/` at the repo root (created lazily,
absence is not an error). See `docs/agents/domain.md`.
